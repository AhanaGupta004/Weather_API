#  Weather App

A modern and responsive Weather Application built using **HTML, CSS, and JavaScript**. Users can search for any city to view the current weather conditions in real time using the **WeatherAPI** service.

---

##  Features

*  Search weather by city name
*  Current temperature
*  Weather condition
*  Humidity information
*  Wind speed
*  Weather icons
*  Search using the **Enter** key or the search button
*  Responsive and clean user interface

---

##  Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* WeatherAPI

##  Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/weather-app.git
```

### 2. Open the project

Open the project folder in **Visual Studio Code** or your preferred editor.

### 3. Get a WeatherAPI Key

Create a free account at:

https://www.weatherapi.com/

Generate your API key.

### 4. Configure the API Key

Open **script.js** and replace:

```javascript
const apiKey = "YOUR_API_KEY_HERE";
```

with

```javascript
const apiKey = "YOUR_ACTUAL_API_KEY";
```

### 5. Run the Project

Simply open **index.html** in your browser.
